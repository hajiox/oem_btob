# OEM請求書（第2段階）

## 実装

- 正式発注受付済み→前金請求、製造数量・最終金額確定済み→残金請求。
- 見積/最終金額は税別。管理者が8%・10%・課税対象外の内訳を明示入力し、合計一致を必須化。税額は税率ごとに円未満切捨て。
- 前金は税込総額の50%（円未満切捨て）、残金は確定税込総額−前金入金実績。税区分は自動推定しない。
- 発行者・振込先・登録番号（任意）・宛先・明細・金額・期限を発行時に固定。1注文1段階1枚。訂正/取消再発行は後続段階で対応。
- 発行と入金予定の作成はDBトランザクション。同額・同期限の既存予定のみ再利用。発行後の入金予定額・期限変更を禁止。
- その段階の入金記録が既にある場合は新規発行/新規送信を停止。残金発行には前金の全額一致入金が必要。
- 印刷用HTML請求書を管理者ページと署名付き顧客専用URLで表示。「印刷・PDF保存」で保存可能。PDFファイルのメール添付ではなく専用リンクを送信。
- 顧客URLは第三者共有不可のBearer URL。検索掲載/キャッシュ/外部参照/外部アセットなし。注文取消時は顧客URL無効。期限切れは設けず、署名鍵変更時は既存URLが無効になる。
- メールはstaff@aizu-tv.comから既存案件メール機能経由。宛先・金額を確認後に別ボタンで送信。安定した送信IDで二重送信防止。未確認状態はメール同期で確認し、勝手に再送しない。
- 登録番号未設定でも通常の請求書は作成可。「適格請求書」としての充足は保証しない。商品明細・取引日等の必要事項は実案件に合わせて発行者が確認する。
