# OEM 送料・発送梱包手数料

- `/btob` の全商品・全プランに、1注文につき6,000円（税別）を加算。
- 商品単価×数量と割合調整を計算した後に1回だけ加算する。商品単価には含めない。
- 結果は商品小計、送料・発送梱包手数料、概算合計の3項目を表示。
- 販売シミュレーションは送料等別の商品単価を使うことを明示。
- 申込総額・保存データ・通知メールに同じ合計と明細を渡す。実送信でのテストは行わない。
- お茶: バルク250,000+6,000=256,000円、4包パッケージ100,000+6,000=106,000円。
- 他LPには加算しない。商品・選択肢のDB価格と製造条件は変更しない。

検証: 6商品共通の手数料、他ページと未選択の0円、代表商品小計への加算をNodeで確認。通常Chrome画面操作で見積もり表示を確認する。
