## 事業・顧客体験

- 対象は福島の農家・農園、地域事業者、道の駅・観光施設、オリジナル商品を作りたい店舗。地域の素材や店の味を自社ブランドの商品にする食品OEM。新規流入を得るサイトであり、DocScannerのFAX・メール営業とは役割を分ける。
- 訴求の核は味づくり。自社のカレー・ラーメン販売と楽天/Yahooの過去のランキング実績は安心材料として控えめに示す。順位・レビューは対象商品と時点を明記し、OEMの品質・売上保証にしない。詳細は `docs/oem-ranking-evidence-20260920.md` など。
- LPは情報過多を避け、画像を増やしすぎない。重要な説明は読みやすいテキスト、補足は必要な範囲で折りたたむ。BTOは商品画像から選び、不要な製造数入力や「選択して次へ」の反復を避ける。商品カテゴリーを恣意的に畳まない。
- 商品群: レトルトカレー、土産向け2食入りラーメン、たれ・ソース・ドレッシング、ふりかけ、ジャム・ご飯のお供の瓶詰め、ティーバッグ茶。容器の写真風画像はBTOの仕様確認に、統一したイラストはLPの幅広い製造イメージに使う。既存商品の写真とAI生成サンプルを混同しない。
- 基準ロットは多くの商品で約400個。ラーメンは約400セット（2食入り）、お茶は4包×400個または50包×100袋の専用プラン。商品ごとの現行仕様・価格はBTOと `docs/bto-20260916.md` などで確認する。概算は正式見積もりではなく、原料・製造可否・ロットの条件で変わる。
- 初回特典は1企業（個人は1名）につき1回だけ。通常は試作2回まで10,000円、原材料表示5,000円、栄養成分の計算値5,000円、簡易パッケージデザイン30,000円の計50,000円を初回0円にする。追加試作は1回3,000円。製造費・原料等実費・送料は無料ではない。根拠: `docs/oem-offer-20260919.md`、現行画面。
- 2026-10-04時点の現行BTOでは製造費180円/単位、送料・発送梱包手数料6,000円/注文を概算に含む（税別）。製造実数による精算、正式発注後の前金50%、入金確認後の製造着手、出荷前の残額支払いは `src/lib/oem-terms.ts` と正式見積・契約画面で再確認する。お茶は原料支給が必須。高粘度のパウチ充填や乾燥しにくい原料など、受託できない場合がある。
