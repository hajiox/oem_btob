# OEM見積もりのワンクリック選択

- 対象: `/btob` のみ。他LP・編集システム・既存の価格データは変更しない。
- 商品カードは押すだけで仕様選択へ進む。
- 単一選択の質問はボタンとして表示し、そのクリックで分岐先または概算へ進む。戻って同じ選択肢を押しても進める。
- 文字入力・複数選択では明示的な次へ、申込送信では明示的な送信を維持。
- お茶の原料支給「ない」はその場で受付条件を表示し、概算へ進めない。
- 選び直し時は後続回答を消去し、変更前の価格や原料名を持ち越さない。
- 細かい動的ステップ数・進捗率を商品名と短い案内に置換。画面遷移後は入力領域へフォーカスし、画面外ならスクロール。
- 汎用編集UIへの追従は今後の専用UI設計の制約にしない。今回は既存の確定済み価格・分岐データを再利用し、破壊的な削除は実施しない。

検証: TypeScript と production build が成功。操作・金額の回帰検証は `verify-bto-ui.cjs`、`verify-jar-tea-ui.cjs` を使用する。
