# OEM試作・顧客承認（2026-10-01）

試作は企業識別キーと人・企業確認根拠を管理者が明示して登録する。`oem_trial_ledgers` を行ロックし、同一キーの無料枠を通算2回に限定する。3回目以降は3,000円（税別）の参考表示であり、請求・自動課金は行わない。試作結果は構造化状態と結果メモに保存する。

承認は試作・表示ラベル・最終仕様の内容名、版、固定本文、SHA-256をスナップショットとして保存し、32バイトランダムBearer tokenのハッシュだけをDBに保存する。発行は保存のみでメール送信しない。顧客リンクは1回だけ承認または修正依頼でき、期限・IP・UA（HMAC）・時刻を記録する。既存の正式発注仕様を上書きしない。発注に紐付けた承認は製造開始前の確認材料として利用し、pending/changes_requestedが残る場合はDB側ゲートで開始を拒否する。

確認: `node scripts/verify-oem-trials-approvals.cjs --with-migration` の実PGロールバック検証を通過。試作の追加費は案件3回目以降であり、通常案件の最初の2回に追加費を加えない（基本試作費10,000円は正式見積で扱う）。管理画面へ統合済み。製造状態更新のDBトリガー、RLS、スナップショット・監査の不変性、旧版失効・同一操作の再確認を検証。高負荷の同時実行試験は実施していない。全体の検証は `oem-operations-completion-20261001.md` 参照。
