# OEM正式発注・規約同意

## 実装範囲

- 管理画面から正式見積額と最終仕様を固定して、期限付きの正式発注URLを発行する。
- 発行時点の見積スナップショット、規約本文、規約版、各SHA-256を保存する。
- お客様は専用ページで見積・仕様・規約を確認し、発注者名の入力と規約同意チェックを完了しないと正式発注できない。
- 同意記録は発注時点の会社名・担当者名・メール、規約版、見積・規約ハッシュ、IP・User-AgentのHMACハッシュ、日時を保存する。生のIPは保存しない。
- 規約同意後のみ、前金入金済み、製造中、残額請求中、全額入金済み、出荷済みの順で進行できる。
- 規約同意前の工程進行は、画面だけでなくサーバー処理とDB制約でも拒否する。
- 発注URL再発行時は以前のURLを無効にする。

## 運用

1. OEM案件で「正式発注・規約同意」を開く。
2. 正式見積額と正式な商品仕様を確認し、「正式発注を発行してメール送信」を押す。
3. お客様の同意後、状態が「正式発注受付済み」になる。
4. 入金・製造・最終金額確定・出荷に合わせて工程を順番に更新する。

メール送信に失敗しても発注自体は二重作成せず、管理画面に今回だけ表示されるURLから状況を確認する。再送が必要な場合は「期限を延長して発注リンクを再送」を使う。

## 検証

- `node scripts/verify-oem-orders.cjs`
- `npm run lint -- --max-warnings=0`
- `npm run build`

検証スクリプトはトランザクションをロールバックし、RLS・権限・未同意時の進行拒否・同意の冪等性・改ざん検知・期限切れ拒否を確認する。
